# Product Requirements Document (PRD)
**Project:** Daycare Management App (MVP)

## 1. Product Vision
To provide a seamless, real-time communication platform between daycare caregivers and parents, ensuring peace of mind through transparent, fast, and effortless daily activity tracking.

## 2. Target Audience
*   **Daycare Admins:** Needs a simple web dashboard to manage children, staff, and classes.
*   **Caregivers (Pengasuh):** Needs a highly responsive, one-handed mobile app to input data quickly without interrupting childcare duties.
*   **Parents (Orang Tua):** Needs a passive monitoring app that pushes real-time updates and daily summaries of their child.

## 3. Scope of MVP
**In Scope:**
*   Check-in & Check-out attendance tracking.
*   Real-time activity timeline (Eat, Sleep, Toilet, Play).
*   Instant photo/video capture and background upload.
*   Push notifications for parents.
*   Admin dashboard for master data management (Go + HTMX).

**Out of Scope (Post-MVP):**
*   CCTV/IP Camera integrations (RTSP/WebRTC).
*   Automated billing and invoicing.
*   Curriculum and grading modules.

## 4. User Stories
*   **Admin:** As an admin, I want to add a child's profile and link it to a parent's email so that the parent can access their child's timeline.
*   **Caregiver:** As a caregiver, I want to log a child's meal in under 3 taps so that I can immediately return to feeding them.
*   **Parent:** As a parent, I want to receive a push notification when my child falls asleep so I have peace of mind while working.
